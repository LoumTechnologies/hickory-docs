# Hickory Docs

Hickory Docs is an IDE for literate Markdown. Write the explanation, code, and checks that belong together in one document. That document can generate real project files and trace those files back to the source that produced them.

This page is a read-only document open in Hickory's Simple Browser interface. Use the line gutter to fold a section, or select text to copy it.
