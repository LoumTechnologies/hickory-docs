# Edit authored source through the document and output views

For engineers implementing this part of Hickory.

The same construction is visible as Markdown and as generated files. Editing
requires more than matching text: the UI must retain byte provenance, translate
editor offsets and refuse reverse edits into immutable captures. An authored
patch remains the place to change a scaffolded program.

An authored patch can be saved as a draft, but [downstream construction must revalidate](guarantees/literate-projects/patch-edits-revalidate-downstream-construction/contract.md) before treating it as an applicable change. Captured base bytes remain immutable in either view.
