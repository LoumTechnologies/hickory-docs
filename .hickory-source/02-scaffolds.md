# 2. Capture a scaffold, then author the change

Our workspace started with Cargo-generated bytes. We want to keep those bytes
without making readers study boilerplate, and we want a clone to reconstruct the
project without rerunning Cargo. We will capture an inline base, authenticate it,
and apply our authored changes as explicit patches.

## Give the capture one content identity

A capture is a set of paths and their exact contents. Sort the paths, then hash
each path and body with a length prefix so different boundaries cannot describe
the same byte sequence. This is the existing ingestion format; keep it compatible
with authentic captures already stored in documents.

<a id="immutable-scaffold-fingerprint"></a>
<book:copy id="immutable-scaffold-fingerprint">
//! Captured scaffold files are an immutable, self-contained base for patches.
use crate::{HickDocument, HickNode};
use sha2::{Digest, Sha256};
use std::collections::BTreeMap;

/// Hash the captured paths and bytes, never a cache key or a generator command.
pub fn scaffold_fingerprint(files: &BTreeMap<String, String>) -> String {
    let mut hasher = Sha256::new();
    for (path, content) in files {
        hasher.update((path.len() as u64).to_le_bytes());
        hasher.update(path.as_bytes());
        hasher.update((content.len() as u64).to_le_bytes());
        hasher.update(content.as_bytes());
    }
    format!("{:x}", hasher.finalize())
}
</book:copy>

Next validate the captured shape and digest before evaluating any construction.
Reject nested operations or metadata that this text-only hash does not cover.

## Turn a real command into that inline base

Let the author select one producer explicitly. Execute it, read its named output
volume, filter ignored build products and retain the source bytes in Markdown.
Before accepting the updated document, replay it and compare every captured file.
The [capture contract](guarantees/authoring/ingest-owns-what-a-scaffolder-wrote/contract.md)
requires those bytes to survive a clone, so a transcript-cache reference is insufficient.

## Prove that a patch changes the result without rewriting the base

Use a retained Cargo-shaped capture, then add a greeting with an authored patch.
Replay must produce the greeting without a command transcript. Compare the whole
result with direct file construction, and break the patch context to demonstrate
exact refusal. This tests replay; the next witness tests actual execution.

<a id="f-d5caa71df0d7-owned_ingest_is_editable_source_without_claiming_generator_execution"></a>
<book:copy id="f-d5caa71df0d7-owned_ingest_is_editable_source_without_claiming_generator_execution">
// Guarantee: docs/guarantees/literate-projects/markdown-constructs-the-complete-project.md
#[tokio::test]
async fn owned_scaffold_accepts_patches_without_generator_execution() {
    // The command is retained as provenance, never executed during replay.
    let source = format!(
        r#"<hick:project/>
<hick:exec id="scaffold" container="sdk">
<hick:copy>cargo init --name seed --vcs none out</hick:copy>
<hick:ingested sha256="{}">
<hick:file id="owned" path="src/main.rs">
fn main() {{}}
</hick:file>
<hick:file path="Cargo.toml">
[package]
name = "seed"
version = "0.1.0"
</hick:file>
</hick:ingested>
</hick:exec>

Give the first executable an observable greeting.
<hick:patch id="greeting" after="scaffold">
--- a/src/main.rs
+++ b/src/main.rs
@@ -1 +1 @@
-fn main() {{}}
+fn main() {{ println!("Hello, Hickory!"); }}
</hick:patch>
"#,
        hick_lang::scaffold_fingerprint(&std::collections::BTreeMap::from([
            ("src/main.rs".into(), "fn main() {}\n".into()),
            (
                "Cargo.toml".into(),
                "[package]\nname = \"seed\"\nversion = \"0.1.0\"\n".into()
            ),
        ]))
    );
    let result = hick_literate::run_pipeline_weave(&[("project.md", &source)], &[], None)
        .await
        .unwrap();
    assert!(result.transcripts.is_empty());
    assert_eq!(
        result.files["src/main.rs"].as_text(),
        Some("fn main() { println!(\"Hello, Hickory!\"); }\n")
    );
    assert!(matches!(
        result.provenance_maps["Cargo.toml"].spans()[0].origin,
        hick_exec::node::SourceOrigin::Ingested { .. }
    ));
    // Compare complete trees, not just the changed entry point. Reconstruction
    // before and after reorganizing the source must agree on all outputs.
    let plain = "<hick:project/><hick:file path=\"src/main.rs\">fn main() { println!(\"Hello, Hickory!\"); }\n</hick:file><hick:file path=\"Cargo.toml\">[package]\nname = \"seed\"\nversion = \"0.1.0\"\n</hick:file>";
    let before = hick_literate::run_pipeline_weave(&[("project.md", plain)], &[], None)
        .await
        .unwrap();
    assert!(
        before
            .evaluated_project
            .unwrap()
            .new
            .compare(&result.evaluated_project.unwrap().new)
            .is_empty()
    );
    let invalid = source.replace("-fn main() {}", "-fn main() { changed(); }");
    assert!(
        hick_literate::run_pipeline_weave(&[("project.md", &invalid)], &[], None)
            .await
            .is_err()
    );
}
</book:copy>

## Keep authored changes editable and the capture immutable

Finally protect the editor boundary. A visual read-only label cannot stop a
full-text replacement or an output edit. Compare source transactions, protect
captured output ranges and allow authored patch changes. Keep each captured file
folded on arrival so the explanation and patch remain the interesting part.
