# Build web applications with explicit request decisions

For C# application authors and evaluators testing whether compiler-checked values
and visible control flow improve basic web development. This construction builds
reusable libraries plus a durable task application with accounts, sessions, HTML
forms and a JSON API. It replaces the initial CORS-only demonstration.

Start with the core, then storage and identity, then the host and the complete
application. The final chapters provide independent HTTP acceptance tests,
compiler witnesses, and a bounded evaluation protocol. A working application is
necessary evidence; it is not evidence of AI productivity by itself.
