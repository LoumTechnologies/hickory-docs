## Consequential assumptions

- The existing local-only server and host executor own filesystem, process,
  provider and credential authority. Window IDs route requests; they do not
  authenticate a caller or sandbox independently permitted ACP/terminal processes.
- Monty snippets cannot access shell/filesystem directly. Registered host terminal
  actions can execute processes with existing host permissions. Document edit
  tools retain exact-preview approval; instructions forbid using terminals to
  bypass it. This is not an adversarial same-user process sandbox.
- UI handles bind current controller revisions; they are not complete edit
  baselines or authenticated semantic evidence. Receipts bind requested/actual
  outcomes; cancellation cannot promise rollback or crash exactly-once execution.
- Review origin is a local declaration. Agent adapters mark agent-declared and
  cannot resolve/reopen through that path. Local clients/storage can still be
  edited. The coach requires user-declared criterion/resolution events.
- Source guards capture the root source once and compare the expected digest
  before parsing/execution. They do not freeze dependencies, the OS or external
  services. Captured source identity and successful execution remain separate.

Alternatives rejected: synthetic DOM clicks, treating a job request as a pass,
claiming every callback has parity because an AST scan found it, substituting
recorded browser proposals for a real provider, or publishing unreviewed sessions.
