# Change a behavior without losing its evidence

For: Hickory maintainers, authors and reviewers changing this guarantee-organized codebase.

Start with the behavior a stakeholder needs. Read its contract, follow the actual implementation and tests, then inspect its limits. The Markdown source is canonical. Generated application files remain committed for builds. See [the maintainer workflow](docs/developers/literate-workflow.md) for generation, focused checks and recovery.

Choose a task:

- [Write and edit a document](.hickory-source/guarantees/authoring/index.md).
- [Reorganize the generated project](.hickory-source/guarantees/literate-projects/index.md).
- [Review a result or prediction](.hickory-source/guarantees/verification/index.md).
- [Trace or edit generated bytes](.hickory-source/guarantees/lineage/index.md).
- [Review an agent change](.hickory-source/guarantees/agent/index.md).
- [Decide what can execute](.hickory-source/guarantees/execution/index.md).
- [Pair machines or inspect local persistence](.hickory-source/guarantees/collaboration/index.md).
- [Publish or install a build](.hickory-source/guarantees/release/index.md).

The contract pages retain unresolved review work. Historical hosted contracts are labeled explicitly. Source references establish navigation; they do not make an unrun test pass or settle a product decision.
